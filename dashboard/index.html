Interactive Attack & Containment Walkthrough

Scripted scenario sequence based on Docs/08_Demo_Script.pdf. Demonstrates containment of a compromised agent with valid credentials while benign peers remain completely unaffected.

0:00 - 0:30

1. Healthy Baseline Workload

Both agents operate normally with valid bearer credentials. Gateway processes requests with 0 drift points.

TALKING POINT: "Notice both agents hold valid bearer tokens. Standard IAM checks whether credentials are valid; here, both are 100% authenticated."
1:00

2. Untrusted Document Ingestion (Provenance Taint)

procurement-bot-04 reads supplier_invoice.pdf containing an indirect prompt injection payload. Provenance tag binds to the session.

TALKING POINT: "The agent ingested an untrusted PDF. AIDDS immediately tags the session context as tainted without interrupting safe actions."
1:30

3. Lateral HR Access Attempt (Score: 85 - Restrict)

The hijacked agent attempts to query hr/salaries.xlsx. While the token technically grants database access, the declared role manifest explicitly forbids HR data.

TALKING POINT: "A standard permission check allows this because the token has db read permissions. But AIDDS compares behavior with declared role: HR data is strictly forbidden."
2:00

4. Kill Chain Completion & Automated Quarantine (Score: 100 - Isolate)

The hijacked agent attempts to transmit sensitive payroll records to an external host. Complete kill-chain override triggers instant isolation.

TALKING POINT: "Untrusted read + sensitive data access + external egress: that is the complete injection kill chain. Instant isolation without human intervention."
2:30 - 3:15

5. Targeted Containment: Peer Unaffected

While procurement-bot-04 is quarantined, support-bot-02 continues processing enterprise tickets without system-wide downtime.

TALKING POINT: "Only the compromised agent is restricted. Legitimate enterprise workflows continue uninterrupted."

5-Layer Zero-Trust Agent Security Architecture

Purpose-built for production enterprise environments running LLM tool-calling agents.

1
Autonomous AI Agent
LangGraph, AutoGen, CrewAI, MCP, or custom LLM client issuing tool calls.
→
2
FastAPI Gateway
Inline proxy (latency measured live in the header) intercepting tools, actions, and payload sizes.
→
3
Multi-Signal Detector
Role rules, taint flow, sensitivity, Markov transitions, velocity, honeypots.
→
4
Risk Engine (0-100)
Graduated composite risk calculation with plain-language reason rankings.
→
5
Graduated Response
Observe (0-39) → Step-Up (40-69) → Restrict (70-89) → Isolate (90+).

Implemented System Capabilities

  • Inline FastAPI Interception Gateway with <10ms p95 latency
  • Signed & Versioned YAML Role Manifest Specification & Loader
  • Multi-Hop Context Taint Propagation & Provenance Tracking
  • Graduated Response Controller (Allow, Step-Up, Restrict, Deny)
  • Tripwire Honeypot Resources & Kill-Chain Hard Overrides
  • Clean, Enterprise Security Dashboard with Live SSE Stream
  • 15 Labelled Scenarios with 100% Passing CI Quality Gates
